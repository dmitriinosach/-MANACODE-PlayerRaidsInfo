# Данные Manacode_PlayerRaidsInfo

Проще всего запустить `ОбновитьДанные.exe` из папки аддона: он сам скачает нужное. Таблица ниже — для тех, кто качает руками.

| Файл | Что внутри |
|---|---|
| `season_all.zip` | все сезоны сразу. **Не знаете, что выбрать, — качайте его** |
| `season7.zip` | текущий сезон, без него аддон пустой, 57997 игроков |
| `season6.zip` | прошлый сезон, 14806 игроков |
| `season5.zip` | прошлый сезон, 14936 игроков |
| `season4.zip` | прошлый сезон, 10662 игроков |

Как поставить руками: откройте архив в 7-Zip или WinRAR, пароль `raids-circle`, и распакуйте в `Interface\AddOns` с заменой файлов — данные лягут в `Interface\AddOns\Manacode_PlayerRaidsInfo\data`. Можно и по одному файлу: `Data.lua` и `Data_sN.lua` положить в эту папку `data` самому — не в корень аддона, оттуда он их не прочитает. В игре наберите `/reload`.

`index.json` — служебный файл обновлялки, скачивать его не нужно.
