# Данные Manacode_PlayerRaidsInfo

Проще всего запустить `ОбновитьДанные.exe` из папки аддона: он сам скачает нужное. Таблица ниже — для тех, кто качает руками.

| Файл | Что внутри |
|---|---|
| `season_all.zip` | все сезоны сразу. **Не знаете, что выбрать, — качайте его** |
| `season3.zip` | текущий сезон, без него аддон пустой, 53331 игроков |
| `season2.zip` | прошлый сезон, 14806 игроков |
| `season1.zip` | прошлый сезон, 14936 игроков |
| `season0.zip` | прошлый сезон, 10662 игроков |

Как поставить: откройте архив в 7-Zip или WinRAR, пароль `raids-circle`, распакуйте в `Interface\AddOns` с заменой файлов, в игре наберите `/reload`.

`index.json` — служебный файл обновлялки, скачивать его не нужно.
